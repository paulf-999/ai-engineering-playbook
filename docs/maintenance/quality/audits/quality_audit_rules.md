# 📏 Rule Quality Audit

**Purpose:** for maintainers, whether each Claude rule earns its place and reads correctly, scored out of 10.

- **Kept accurate by:** [`test_quality_audit_rules.py`](../../../../tests/docs/maintenance/quality/test_quality_audit_rules.py), which fails if an entry-point rule has no row or a score doesn't match its themes.
- **Scored by:** one fresh-context reviewer on Sonnet, using the [rules rubric](../themes/quality_themes_rules.md), never the model that wrote the rule.
- **When:** a PR that changes a rule refreshes that rule's row, and each row covers the rule with its children.
