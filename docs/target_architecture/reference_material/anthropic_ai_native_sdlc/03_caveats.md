# ⚠️ AI-native SDLC course: Caveats

**Purpose:** the limits of Anthropic's SDLC course: who it's for, how strong its evidence is, and what it assumes.

This page is part of the [summary of Anthropic's SDLC course](../anthropic_ai_native_sdlc.md). These points are this repo's assessment, not the course's own words.

## ⚠️ Limits

These limits matter here:

- 👥 **Audience:** leads in organisations that already use Claude Code, with the last lesson aimed at large, regulated companies.
- 📏 **Evidence:** the measures it suggests are untested proposals.
  - **Its one figure:** that capturing intent shrinks "a multi-week elicitation and refinement cycle to hours" is an expectation, not a result ([Capture as intent.md](https://academy.claude.com/courses/ai-native-sdlc-playbook/capture-intent)).
- 🏢 **Vendor source:** Anthropic publishes both the course and the tools it recommends.
  - **Basis:** it calls the course its Applied AI team's practice, without saying how that was gathered.
- 🔐 **Organisation features:** several plays need features that an organisation's admins run.
  - **Examples:** settings admins lock for all users, a managed code review service, and exported usage data.
