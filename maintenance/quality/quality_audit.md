# 📊 Quality audit

> [!NOTE]
> **For repo maintainers only:** you don't need this page to install or use the Claude Code instructions.

**Purpose:** the latest scores for the repo as a whole, from each regular review.

The repo is scored against its rubric in [quality rubrics](quality_rubrics.md), and earlier runs are in git history. Tests and rules are checked against their checklists instead, with findings going to GitHub issues.
