# 📐 Quality rubrics

> [!NOTE]
> **For repo maintainers only:** you don't need this page to install or use the Claude Code instructions.

**Purpose:** how a reviewer scores the repo's tests, its rules and the repo as a whole at each regular review.

Each section is one rubric, and the [quality audit](quality_audit.md) holds the latest scores.

## 📚 Sections

- 🧪 **[Tests](quality_rubrics/_tests.md):** how each script's tests are scored, and the brief the reviewer gets.
- 📏 **[Rules](quality_rubrics/_rules.md):** how each rule is scored, and the brief the reviewer gets.
- 🏗️ **[Repo](quality_rubrics/_repo.md):** how the repo as a whole is scored for bloat and over-engineering, with the measures to run.
