# 📐 Quality rubrics

> [!NOTE]
> **For repo maintainers only:** you don't need this page to install or use the Claude Code instructions.

**Purpose:** how a reviewer scores the repo as a whole, checks its rules and tests, and gets blind reviews from its likely users.

The [quality audit](quality_audit.md) holds the latest scores, and checklist findings go to GitHub issues.

## 📚 Sections

- 🏗️ **[Repo](quality_rubrics/_repo.md):** how the repo is scored for bloat and over-engineering, with the measures to run and the rules and tests checklists.
- 👥 **[Personas](quality_rubrics/_personas.md):** blind reviews from a data engineer, a data analyst and an engineering manager, and how to rank the feedback they share.
