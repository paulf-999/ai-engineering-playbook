# 📐 Quality rubrics

> [!NOTE]
> **For repo maintainers only:** you don't need this page to install or use the Claude Code instructions.

**Purpose:** how a reviewer checks the repo's tests and rules, scores the repo as a whole, and gets blind reviews from its likely users.

Tests and rules each have a checklist whose findings go to GitHub issues, and the repo has a rubric whose latest scores the [quality audit](quality_audit.md) holds.

## 📚 Sections

- 🧪 **[Tests](quality_rubrics/_tests.md):** the checklist for each script's tests, and the brief the reviewer gets.
- 📏 **[Rules](quality_rubrics/_rules.md):** the checklist for each changed rule, and the brief the reviewer gets.
- 🏗️ **[Repo](quality_rubrics/_repo.md):** how the repo as a whole is scored for bloat and over-engineering, with the measures to run.
- 👥 **[Personas](quality_rubrics/_personas.md):** blind reviews from a data engineer, a data analyst and an engineering manager, and how to rank the feedback they share.
