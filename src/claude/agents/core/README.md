# 🤖 Core agents

**Purpose:** indexes the core agents, which skills and the user hand focused work to, and which install under `agents/core/` in your Claude config directory.

| Agent | What it does |
|---|---|
| 🔍 [`code-reviewer`](code-reviewer/AGENT.md) | Reviews a PR or diff against the repo's own rules, returning a verdict, six theme scores and prioritised fixes |
| ✍️ [`technical-writer`](technical-writer/AGENT.md) | Drafts a PR body or new Confluence page suited to its audience, for a skill or the user to publish |
