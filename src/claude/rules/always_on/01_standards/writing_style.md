# ✏️ Writing style

**Purpose:** how to write everything you produce, from replies to commit messages.

- ✂️ **Brevity:** cut any sentence or caveat that can go without losing meaning, and keep one idea per sentence.
- 🎯 **Lead with what it does:** say what something does before how it works, and define each term the first time it appears.
- 🛂 **Review before sending:** show the user anything meant for an external system, such as a Jira ticket or an email, and send it only once they approve.
- 📜 **History lives in git:** describe only the current state in repo files, and leave past changes to git.
