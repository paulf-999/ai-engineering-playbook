# 👤 Preferences

**Purpose:** rules that are one person's taste in how Claude replies, lays out docs and keeps their own files, such as the reply format or saved plans. The rules in this folder load in every session.

- 📦 **Installs:** Only with `make install PREFERENCES=1`, and never into a one-repo install.
- 🧭 **Belongs here:** a rule goes here when the maintainer has ruled it a personal preference, per the [rule kinds guide](../../../../../docs/guides/authoring_guide/_rule_kinds.md).
- 🔀 **Elsewhere:** the other kinds sit beside this folder, in `01_standards/` and `02_team_conventions/`.

This README is for people browsing the repo. The installer leaves it out, so Claude never loads it.
