# 🗂️ Working files

**Purpose:** where Claude keeps your own plans, TODOs, drafts, error write-ups and session notes, outside every repo. It's a preference, installed only with `make install PREFERENCES=1`.

- 💾 **Checkpoints:** once a task spans many files or turns, write its decisions and open items to `.claude_work/_sessions/YYYY_MM_DD_<topic>.md` in your home folder, beside the saved plans, as an absolute path, so a later session can resume it.

## 📚 Read on demand

- `on_demand/preferences/working_files/_saving_plans.md`, in your Claude config directory, once a plan is approved.
- `on_demand/preferences/working_files/_todo_logging.md`, when the user asks to add something to their TODOs.
- `on_demand/preferences/working_files/_drafts_and_errors.md`, before saving a draft or an error write-up.
