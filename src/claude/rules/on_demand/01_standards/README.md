# 🧰 Standards

**Purpose:** rules that are good practice for anyone using the tool, whatever their team, such as quoting bash variables or using dbt's `ref()`. The rules in this folder load only when another rule points Claude to them.

- 📦 **Installs:** Always, with every install.
- 🧭 **Belongs here:** a rule goes here when it would hold for any team using the tool, per the [rule kinds guide](../../../../../docs/guides/authoring_guide/_rule_kinds.md).
- 🔀 **Elsewhere:** the other kinds sit beside this folder, in `02_team_conventions/` and `03_preferences/`.

This README is for people browsing the repo. The installer leaves it out, so Claude never loads it.
