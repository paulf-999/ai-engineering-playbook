# 🏢 Team conventions

**Purpose:** rules that are this team's own choices for its shared work, such as its dbt layer prefixes, folder layouts or CI tools. The rules in this folder load only when another rule points Claude to them.

- 📦 **Installs:** With every install, since the repo starts the team from its conventions. Another team replaces this folder in its own copy of the repo.
- 🧭 **Belongs here:** a rule goes here when it names this team's files, tools, teams or roles, or picks a style the tool's own guide doesn't, per the [rule kinds guide](../../../../../docs/guides/authoring_guide/_rule_kinds.md).
- 🔀 **Elsewhere:** the other kinds sit beside this folder, in `01_standards/` and `03_preferences/`.

This README is for people browsing the repo. The installer leaves it out, so Claude never loads it.
