# 📂 path_scoped

**Purpose:** rules that load when Claude works on a file matching the rule's `paths:` list, with style guides in one folder and other rules sorted by [kind of rule](../../README.md#-three-kinds-of-rule).

| Folder | What it holds |
|---|---|
| 🧰 [`01_standards/`](01_standards/) | Good practice for anyone using the tool, whatever their team, such as secure coding and testing |
| 🎨 [`style_guides/`](style_guides/) | Each tool's style guide, with this team's conventions for it alongside |
