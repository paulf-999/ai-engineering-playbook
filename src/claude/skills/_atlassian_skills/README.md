# 🔗 Atlassian skills

**Purpose:** indexes the skills for this team's Jira and Confluence work, which install flat under `skills/` in your Claude config directory, and which need the Atlassian MCP server.

| Skill | What it does |
|---|---|
| 🎫 [`/jira-create-issue`](jira-create-issue/SKILL.md) | Drafts one Jira ticket from the team's conventions, and creates it once you approve the draft |
| 📄 [`/confluence-create-page`](confluence-create-page/SKILL.md) | Drafts a Confluence page from the team's patterns, and creates it as a Confluence draft once you approve the draft |
