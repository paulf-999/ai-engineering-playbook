# 🤖 Claude skills

**Purpose:** indexes the skills about using Claude Code itself, which install flat under `skills/` in your Claude config directory.

| Skill | What it does |
|---|---|
| 🔁 [`/claude-kaizen`](claude-kaizen/SKILL.md) | Turns recurring corrections in your feedback notes into rules, keeping only those an A/B eval proves, also as a plugin: `/plugin marketplace add paulf-999/ai-engineering-playbook`, then `/plugin install claude-kaizen@ai-engineering-playbook` |
| 📊 [`/claude-capture-session-prompts`](claude-capture-session-prompts/SKILL.md) | Writes one day's prompts to a markdown table, with secrets masked, for review and planning |
