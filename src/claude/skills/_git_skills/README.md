# 🌿 Git skills

**Purpose:** indexes the skills for this team's git workflow, which install flat under `skills/` in your Claude config directory.

| Skill | What it does |
|---|---|
| 🚀 [`/git-create-pr`](git-create-pr/SKILL.md) | Takes your changes to an open GitHub PR, with a branch, commit message and PR body, after one confirmation |
| 🔍 [`/git-review-pr`](git-review-pr/SKILL.md) | Reviews a GitHub PR with the `code-reviewer` agent, and posts a scored comment once you approve it |
